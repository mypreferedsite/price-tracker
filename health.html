What to do if something is red or orange

  • On GitHub open Actions, choose Collect prices and press Run workflow. Wait a minute and reload this page. If the run shows a red cross, open it and read the last lines.
  • If an asset has few hourly points (for example Platinum, Bitcoin or Ethereum right after the upgrade), run Load past prices once the same way.
  • Open data/status.json in your repository: it lists which source each price came from and any warning.
  • On weekends currencies and metals are closed, so only crypto prices are expected.
  • Orange or red on a single asset usually means its source failed for a while. If it stays that way for a day, send the text of data/status.json and the error line of the failed run to get it fixed.
